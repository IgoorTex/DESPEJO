# DESPEJO · Larissa Nobrega

Site estático com imagens, capas e três vídeos otimizados.

Envie a pasta despejo inteira para a raiz do repositório psicologalarissanobrega para servir em /despejo/. Preserve os nomes e a estrutura. Não envie o ZIP sem extrair.

Para visualizar localmente: python3 -m http.server 8000 e abra http://localhost:8000/despejo/.
